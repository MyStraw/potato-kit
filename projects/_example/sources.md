## 주의사항

### Titanic
- Kaggle 원본이 아니라 공개 미러다. 행 수(891/418)는 원본과 일치함을 확인했다.
- `sample_submission.csv`가 미러에 없어 대회 공식 규격(`PassengerId,Survived`)을 따랐다.

### 부산 기온
- **관측소가 아니라 재분석 격자 자료다.** Open-Meteo는 ERA5 등 재분석 데이터를
  좌표로 보간해 제공한다. 기상청 부산관측소 실측치와 **정확히 일치하지 않는다.**
  공식 통계가 필요하면 기상청 기상자료개방포털(data.kma.go.kr, API 키 무료)을 써야 한다.
- 좌표는 부산시청(35.1796, 129.0756) 한 점이다. 부산 전역을 대표하지 않는다
  (해안·내륙 차이가 있다).
- 마지막 연도는 재분석 자료 갱신 시점에 따라 값이 소급 수정될 수 있다.
- **11년은 기후 추세를 논하기에 짧다.** 기술통계 이상으로 쓰지 말 것.
- 비상업적 사용 무료. 대량 요청 시 제한이 있어 호출 간격 0.3초를 뒀다.

## 국내 공식 소스를 쓰려면 (키 필요)

이번 시운전은 **키 없이 되는 소스**로 했다. 실제 과제에서는 아래를 쓴다.

| 필요한 것 | 소스 | 키 |
| --- | --- | --- |
| 기상 관측 실측 | 기상청 기상자료개방포털 (data.kma.go.kr) | 무료·즉시 |
| 인구·가구·고용 | KOSIS (kosis.kr/openapi) | 무료·즉시 |
| 아파트 실거래가 | 국토부 / 공공데이터포털 (data.go.kr) | 무료 (일부 승인 1~2일) |
| 부산 지역 데이터 | 부산 빅데이터포털 (bigdata.busan.go.kr) | 소스별 상이 |

키는 `.env`에 넣고 `.gitignore`에 추가한다. 코드에 직접 쓰지 않는다.
