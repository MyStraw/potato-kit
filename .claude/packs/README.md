# 전공 팩 (Domain Packs)

팩은 **"이 전공을 하려면 어떤 도구가 붙어야 하는가"를 적어둔 파일**이다.
`/potato-add-pack <이름>`이 이 파일을 읽고 설치를 수행한다.

## 지금 있는 팩

| 파일 | 이름 | 분야 |
| --- | --- | --- |
| `medical.md` | `medical` | 의료·약학·바이오 |
| `medical-plus.md` | `medical-plus` | 화합물·단백질 (약물 설계) |
| `finance.md` | `finance` | 금융·시계열 |
| `libsci.md` | `libsci` | 문헌정보·계량서지 |
| `ocean.md` | `ocean` | 해양·환경·기상 |
| `industrial.md` | `industrial` | 산업공학·최적화 |
| `korea.md` | `korea` | 한국 공공데이터 |

## 새 팩 만들기

**목록에 없는 전공이라도 팩을 만들면 된다.** 방법은 두 가지다.

### 방법 1 — Claude에게 시킨다 (쉬움)

```
/potato-add-pack new <분야 이름>
```

또는 그냥 말로:

```
나 재료공학 하는데 potato-kit 에 재료 팩 만들어줘.
결정구조·물성 데이터베이스 쓸 수 있게.
```

Claude가 해당 분야의 공개 데이터베이스와 MCP 서버를 조사해서 팩 파일을
이 폴더에 만들어준다.

### 방법 2 — 직접 쓴다

이 폴더에 `<이름>.md` 파일을 만들고 아래 형식을 따른다.

````markdown
---
name: 팩이름
title: 사람이 읽는 이름
domain: 분야 설명 한 줄
---

# 팩이름 팩

## 무엇이 붙나
(이 팩을 켜면 무엇을 할 수 있게 되는지 2~3문장)

## MCP 서버

### 서버이름 ✅검증됨 / ⚠️미검증
- **출처**: github.com/... 또는 pypi/npm 패키지명
- **필요**: API 키 필요 여부, 무료/유료
- **설치**:
  ```bash
  conda run -n potato pip install <패키지>
  claude mcp add -s user <이름> -- conda run --no-capture-output -n potato python -m <모듈>
  ```
- **제공 도구**: 무엇을 조회할 수 있는지

## 파이썬 패키지
```bash
conda run -n potato pip install <패키지들>
```

## 감사 체크리스트
methods-reviewer 가 이 분야에서 추가로 볼 항목.
(없으면 "공통 체크리스트만 적용" 이라고 쓴다)

## 데이터 소스 메모
MCP 없이 코드로 접근해야 하는 소스들. URL과 접근 방법.
````

### 표기 규칙

- **✅검증됨 / ✅연결 확인됨** — 실제로 설치하고 MCP 연결까지 확인한 명령
- **✅패키지 확인됨** — 패키지가 레지스트리(PyPI/npm)에 실재함은 확인했으나
  연결 테스트는 안 한 것
- **⚠️미검증** — 문서상 존재하지만 이 킷에서 확인하지 않은 명령.
  `/potato-add-pack`이 설치 전에 패키지가 실제로 있는지 확인하고, 없으면
  대안을 찾아서 알려준다.
- **⚠️패키지 못 찾음** — 조사 시점에 레지스트리에서 찾지 못한 것.
  팩 본문에 적힌 대안(파이썬 코드로 직접 접근)을 쓴다.

미검증이라고 못 쓰는 게 아니다. 다만 **설치가 실패할 수 있으니 그때
Claude에게 "이거 설치 실패했어, 대안 찾아줘"라고 하면 된다.**

## 팩 설계 원칙

1. **조회는 MCP, 계산은 코드.** 외부 데이터베이스를 읽어오는 일은 MCP가 낫고,
   최적화·시뮬레이션·수집 스크립트는 파이썬이 낫다. 최적화 라이브러리를 MCP로
   감싸려 하지 말자.
2. **한 팩은 한 전공.** 여러 분야를 한 팩에 밀어 넣으면 안 쓰는 도구가
   컨텍스트를 먹는다.
3. **API 키가 필요하면 어디서 받는지 적는다.** 링크만 적어두면 나중에 못 찾는다.
4. **감사 체크리스트를 꼭 채운다.** 분야마다 고유한 함정이 있고, 이게 팩의
   진짜 가치다. MCP는 나중에 대체될 수 있지만 이 지식은 남는다.
