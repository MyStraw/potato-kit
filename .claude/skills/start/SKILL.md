# /start — 연구 프로젝트 시작

```
/start
/start 부산 청년 주거 분석
/start 해커톤. 의료 데이터. 이틀 남음
```

**이 스킬이 필요한 이유**: 스킬·에이전트·팩은 유저 스코프라 어디서든 동작하지만,
**운영 규칙(`CLAUDE.md`)은 폴더에 있어야 적용된다.** Claude Code는 현재 폴더와
상위 폴더의 `CLAUDE.md`만 자동으로 읽는다. `/start`가 그걸 놓아준다.

---

## 절차

### 1. 상황 파악

이미 초기화된 폴더인지 먼저 본다.

```bash
ls CLAUDE.md plan.md data/ 2>/dev/null
```

- `CLAUDE.md`가 이미 있으면 → 덮어쓰지 않는다. 무엇이 있는지 보고하고 물어본다.
- 빈 폴더면 → 새로 만든다.
- 데이터·코드가 이미 있으면 → 무엇이 있는지 훑고, 그에 맞춰 `plan.md`를 채운다.

### 2. 프로젝트 성격을 정한다

사용자가 안 알려줬으면 **물어본다.** 이게 규칙을 좌우한다.

```
어떤 성격의 작업인가요?
  1. 해커톤·경진 — 속도 우선, 검증은 제출 직전 한 번
  2. 논문·랩 연구 — 엄밀성 우선, 단계마다 감사
  3. 기관·정책 과제 — 설명 가능성 우선, 비전공자도 읽히게
  4. 그냥 탐색 — 규칙 최소로
```

### 3. 데이터 제약을 확인한다 — 빠뜨리지 말 것

```
이 프로젝트 데이터에 외부 반출 제한이 있나요?
  (환자 기록, 기업 내부 자료, DUA·IRB 조건이 걸린 데이터 등)
```

**"모르겠다"고 하면 제한이 있는 것으로 가정한다.** 나중에 푸는 게
잘못 노출한 걸 되돌리는 것보다 쉽다.

### 4. 폴더 구조를 만든다

```
<프로젝트>/
├── CLAUDE.md        ← 이 프로젝트 규칙 (성격·데이터 제약 반영)
├── plan.md          ← 목표와 진행 기록
├── data/
│   ├── raw/         원본 (읽기 전용으로 다룬다)
│   └── processed/   가공 결과
├── notebooks/
├── reports/figs/
└── .gitignore       data/·.env·산출물 제외
```

### 5. `CLAUDE.md` 를 쓴다

킷의 운영 규칙을 **이 폴더에 복사하고**, 위에서 정한 성격·제약을 덧붙인다.

원본: `~/.claude/potato-kit-rules.md` (설치 시 복사됨)
없으면 킷 저장소의 `CLAUDE.md`를 쓴다.

```markdown
# <프로젝트명>

<!-- potato-kit 운영 규칙 (전문 복사) -->
...

---

## 이 프로젝트

**성격**: (2번에서 정한 것)
**데이터 제약**: (3번에서 확인한 것)
**마감**:
```

**규칙 전문을 복사한다.** 링크만 걸면 Claude가 읽지 않는다.

### 6. 필요한 팩을 제안한다

주제를 듣고 맞는 팩을 추천하되, **켜는 건 확인받고** 한다.

```
주제를 보니 medical 팩이 맞을 것 같습니다. 켤까요?
  /add-pack medical  → PubMed·임상시험·유전자변이·OpenFDA
```

### 7. 다음 단계를 안내한다

상황에 맞는 것 하나만 콕 집어준다. 목록을 나열하지 않는다.

| 상황 | 다음 |
| --- | --- |
| 데이터가 없다 | `/find-data <주제>` |
| 데이터를 방금 받았다 | `/eda data/raw/<파일>` |
| 논문부터 봐야 한다 | `/lit-review <주제>` |
| 재현할 논문이 있다 | `/reproduce <논문>` |
| 최적화 문제다 | `/optimize` |

## 보고 형식

```markdown
## 프로젝트 준비 완료 — <이름>

**성격**: 논문·랩 연구 (엄밀성 우선)
**데이터 제약**: 외부 반출 금지 → 원본은 로컬에서만, 모델에는 집계만

만든 것
  CLAUDE.md   운영 규칙 + 이 프로젝트 규칙
  plan.md     목표·질문·진행 기록 (비어 있음 — 채워주세요)
  data/raw, data/processed, notebooks, reports/figs
  .gitignore

**바로 다음**: 데이터가 아직 없으니 `/find-data 부산 청년 주거` 부터 시작하시죠.
```

---

## 주의

- **기존 `CLAUDE.md`를 덮어쓰지 않는다.** 있으면 물어본다.
- **`data/` 안의 기존 파일을 건드리지 않는다.**
- 폴더를 만들 뿐 분석을 시작하지 않는다. 시작은 다음 스킬이 한다.
- git 저장소 초기화는 **하지 않는다.** 사용자가 원하면 그때 한다
  (데이터가 실수로 커밋되는 사고가 흔하다).
