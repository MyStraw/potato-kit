# /eda — 탐색적 데이터 분석

```
/eda data/train.csv
/eda data/train.csv 타깃은 survived 컬럼
/eda 시계열이야. 날짜 컬럼은 date
```

## 원칙

**원본 행을 대화창에 출력하지 않는다.** 스키마와 집계 통계만 본다.
개인정보·환자 데이터라면 샘플 행조차 출력하지 않는다.
(자세한 것은 `CLAUDE.md`의 데이터 보호 절)

`data/`의 원본 파일은 수정하지 않는다.

## 절차

### 1. 데이터 성격 파악

파일을 읽기 전에 크기부터 본다. 수 GB면 청크로 읽거나 샘플링한다.

```bash
conda run --no-capture-output -n potato python -c "
import pandas as pd
df = pd.read_csv('data/train.csv')
print(df.shape)
print(df.dtypes)
"
```

**어떤 종류의 데이터인지 판단한다.** 이에 따라 뒤 절차가 달라진다:
일반(i.i.d.) / 시계열 / 공간 / 개체 반복측정 / 텍스트.
판단 근거를 사용자에게 한 줄로 말한다.

### 2. 기본 점검 (모든 데이터)

- 행·열 수, dtype, 메모리 사용량
- 결측: 컬럼별 비율 + **결측 패턴** (같이 비는 컬럼끼리 묶여 있는가)
- 중복 행
- 상수 컬럼, 고유값이 행 수와 같은 컬럼(ID로 추정)
- 타깃 분포 (불균형 여부, 회귀면 분포 모양)

### 3. 변수별 분석

**수치형**: 분포(히스토그램), 이상치(박스플롯), 왜도, 타깃과의 관계
**범주형**: 카디널리티, 희귀 범주, 범주별 타깃 비율
**전체**: 상관행렬 (수치형끼리), 타깃과의 상관

### 4. 데이터 성격별 추가 분석

| 성격 | 추가로 보는 것 |
| --- | --- |
| **시계열** | 정상성(ADF 검정), 자기상관(ACF/PACF), 계절성 분해, 구조 변화, 결측 구간의 위치, 시간 간격의 규칙성 |
| **공간** | 관측 지점 분포 지도, 공간 자기상관(Moran's I), 지점별 결측·불연속 |
| **개체 반복측정** | 개체당 관측 수 분포, 개체 간 이질성 |
| **의료** | 코호트 정의, 추적 기간, 검열(censoring) 비율, 결측 메커니즘 추정 |
| **텍스트** | 길이 분포, 어휘 크기, 언어 분포 |

**팩이 켜져 있으면 그에 맞는 분석을 자동으로 추가한다.**

### 5. train/test 비교 (둘 다 있으면)

이게 의외로 중요하다. 분포가 다르면 CV 점수를 믿을 수 없다.

- 컬럼 구성이 같은가
- 수치형 분포 차이 (KS 검정)
- 범주형: test에만 있는 범주
- 결측 패턴이 다른가
- ID 중복이 있는가 (→ 누수 신호)

**분포 비교 시 흔히 저지르는 실수 3종** (시운전에서 실제로 걸렸다)

1. **귀무가설 채택** — `p > 0.05`는 "차이가 없다"가 **아니라** "이 검정력으로는
   차이를 못 잡았다"이다. 표본이 작으면 중간 크기 차이도 놓친다.
   → "분포 차이가 없다" ✗ / "이 검정력에서 주변분포 차이를 검출하지 못했다" ○

2. **이산변수에 KS 검정** — `ks_2samp`는 연속분포를 가정한다. 고유값이 몇 개뿐인
   변수(Pclass, SibSp 같은)에 쓰면 p값이 해석 불가다.
   → 이산·범주형은 **카이제곱**이나 **EMD(Wasserstein)** 를 쓴다.
   고유값 개수를 먼저 세고 방법을 고른다.

3. **주변분포 → 결합분포 비약** — 변수별로 분포가 같아도 결합분포나 `P(y|X)`는
   다를 수 있다. "각 변수 분포가 같으니 CV를 리더보드 대리 지표로 믿어도 된다"는
   결론은 근거가 없다. CV-리더보드 간극은 대개 분포 차이보다 **분할 설계**에서 온다.

### 6. HTML 리포트 생성

`reports/eda-<데이터명>.html`로 저장한다. 그림이 포함된 정적 HTML.

```python
# 한글 폰트 (안 하면 그림에서 글자가 깨진다)
import matplotlib.pyplot as plt, platform
plt.rcParams['font.family'] = {
    'Windows': 'Malgun Gothic', 'Darwin': 'AppleGothic'
}.get(platform.system(), 'NanumGothic')
plt.rcParams['axes.unicode_minus'] = False
```

**그림 안에 이모지를 쓰지 않는다.** 한글 폰트에 이모지 글리프가 없어
`⚠`·`✓`·`→` 가 두부(□)로 깨진다. 강조는 색·굵기로, 기호는 ASCII(`*`)로.
(HTML 본문 텍스트에는 이모지를 써도 된다 — matplotlib 이 그리는 텍스트만 문제다)

리포트에는 그림만 넣지 말고 **각 그림 아래에 "이것이 무엇을 말하는지" 한두 문장**을
같이 쓴다. 나중에 보고서에 그대로 옮길 수 있게.

### 7. 요약 보고

대화창에는 리포트 전체가 아니라 **판단에 필요한 것만** 말한다:

```markdown
## EDA 요약 — train.csv

**규모**: 891행 × 12열
**타깃**: survived (0: 61.6%, 1: 38.4%) — 약한 불균형

**바로 처리해야 할 것**
- Age 결측 19.9% — 중앙값 대치로는 부족해 보인다 (Pclass별 분포가 다름)
- Cabin 결측 77.1% — 컬럼 제거보다 "선실 정보 있음" 플래그가 나을 듯

**눈에 띄는 것**
- Sex가 타깃과 매우 강하게 연관 (여성 74% vs 남성 19% 생존)
- Fare에 512.33이 4건 — 동일 티켓 일행. 이상치가 아니라 실제값
- Fare=0이 15건 — 결측이 아니라 무임 승선으로 보임

**주의**
- Ticket 번호가 중복 → 같은 일행이 train/test에 나뉘면 누수 가능성

**제안 방향**
1. Title(호칭)을 Name에서 추출 — Age 결측 대치에 쓸 수 있다
2. FamilySize = SibSp + Parch + 1
3. 검증은 StratifiedKFold (불균형 고려)

리포트: reports/eda-train.html
```
