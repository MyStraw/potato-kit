📖 Toy-Net 논문 같이 읽기 (예시)

Toy-Net: A Padding-Aware Attention Mechanism for Sequence Tagging (가상의 예시 논문)
원본: papers/toy-net.pdf (실제로는 존재하지 않음 — 데모용)
마지막 업데이트: 예시 · Abstract까지 정리됨

개요

시퀀스 태깅에서 패딩 토큰이 어텐션 가중치를 오염시키는 문제를 지적하고, 패딩을 인식하는 마스킹된 어텐션 메커니즘을 제안한다는 가상의 논문입니다. (실제 방법론과 무관한 데모 텍스트)

Abstract

원문
Sequence tagging models that rely on self-attention often suffer when input sequences are padded to a fixed length, as padding tokens can distort the attention distribution.
번역 · 해설
셀프 어텐션 기반 시퀀스 태깅 모델은, 입력을 고정 길이로 맞추려고 넣는 패딩 토큰이 어텐션 분포를 왜곡시킬 수 있어 문제가 된다는 도입부입니다.

이렇게 원문을 그대로 인용(.quote)한 뒤, 바로 아래 번역·해설(.explain)을 붙이는 게 이 템플릿의 기본 단위입니다. 원문에 없는 배경지식을 보충할 때도 이 박스 안에서, "원문이 한 말"과 섞이지 않게 씁니다.
원문
We propose Toy-Net, which masks padding positions before the softmax step, ensuring that attention weight is only distributed across valid tokens.
번역 · 해설
Toy-Net은 소프트맥스를 적용하기 전에 패딩 위치를 마스킹해서, 어텐션 가중치가 실제 토큰에만 분배되도록 한다는 제안입니다. 수식으로 보면 이런 식입니다 (역시 예시):

$$\alpha_i = \frac{\exp(e_i) \cdot m_i}{\sum_{j=1}^{n} \exp(e_j) \cdot m_j}$$

기호의미
$e_i$토큰 $i$의 raw 어텐션 스코어
$m_i \in \{0,1\}$패딩 마스크 — 실제 토큰이면 1, 패딩이면 0
$\alpha_i$정규화된 어텐션 가중치 (패딩 위치는 항상 0)
토이 예시
길이 5로 패딩된 문장에서 실제 토큰은 앞 3개뿐이라고 하면 ($m = [1,1,1,0,0]$), 마스킹 전에는 패딩 위치도 $\exp(e_j)$만큼 분모에 기여해서 실제 토큰들의 가중치가 과소평가됩니다. 마스킹 후에는 분모가 실제 토큰 3개의 합으로만 계산되어 왜곡이 사라집니다. — 이런 식으로 작은 숫자로 손으로 따라가 볼 수 있는 예시를 .example 박스에 넣습니다.
