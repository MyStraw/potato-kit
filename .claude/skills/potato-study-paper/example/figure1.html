가상 논문 Toy-Net의 Figure 1을 세 조각으로 나눠 하나씩 설명하는 데모 페이지입니다.

A. Input Encoding

PANEL A
그림이 보여주는 것 (예시 설명)
입력 문장이 고정 길이 $n$으로 패딩되고, 동시에 마스크 벡터 $\mathbf{m} \in \{0,1\}^n$이 만들어지는 과정을 보여준다고 가정합니다. 실제 사용 시에는 여기에 그림에 그려진 각 화살표·박스가 논문 본문의 어느 수식·설명과 대응하는지 짚어줍니다.

B. Masked Attention Block

PANEL B
그림이 보여주는 것 (예시 설명)
마스킹이 소프트맥스 이전에 적용된다는 걸 보여주는 내부 구조라고 가정합니다. 본문에서 다룬 수식과 연결합니다:
수식 다시 보기
$$\alpha_i = \frac{\exp(e_i) \cdot m_i}{\sum_{j=1}^{n} \exp(e_j) \cdot m_j}$$ (본문 Abstract 절에서 이미 다룬 수식 — 그림 설명 페이지에서 다시 등장할 때는 이렇게 본문으로 되돌아가는 링크를 함께 둡니다.)

C. Tag Prediction

PANEL C
그림이 보여주는 것 (예시 설명)
마스킹된 어텐션 출력이 태그 분류기로 들어가 최종 라벨을 예측하는 과정이라고 가정합니다. 아직 본문에서 안 읽은 뒷부분(예: 손실함수 정의)이 그림에 나와 있다면, 먼저 해당 페이지를 읽어 정확한 수식을 확보한 뒤에 이 설명을 씁니다 — 그림만 보고 추측해서 쓰지 않습니다.
